# Security

Please do not file public issues with private account data, cookies, tokens, or screenshots containing private messages.

If you find a security issue:

1. Open a minimal issue that says a private report is needed, without secrets.
2. Share reproduction details privately with the maintainer once a private channel is available.

Project guardrails:

- Do not log cookies, tokens, passwords, or WebView console messages from login pages.
- Do not bypass captcha, login challenges, anti-abuse checks, device checks, or signed request mechanisms.
- Keep signing keys and `release.properties` out of git.
